Política de privacidade

Publicador dos canais Reis do Corte, Ancient to Silicon, Iron & Byte e Traços Bíblicos.

Quem usa

Somente o próprio autor, para publicar nos próprios canais. O aplicativo não tem cadastro nem usuários externos.

Dados do Google acessados

Apenas a permissão https://www.googleapis.com/auth/youtube.upload, usada para enviar vídeos, títulos, descrições e miniaturas ao canal autorizado. O aplicativo não lê e-mails, contatos, histórico, comentários, inscritos nem dados de outros canais.

Armazenamento

O token de autorização fica guardado só no computador do autor, em arquivo com acesso restrito, fora de qualquer repositório ou serviço de terceiros. Nenhum dado do Google é vendido, compartilhado ou usado para publicidade.

Uso conforme as políticas do Google

O uso de informações recebidas das APIs do Google segue a Política de dados do usuário dos serviços de API do Google, incluindo os requisitos de uso limitado, e os Termos de Serviço do YouTube. Veja também a Política de Privacidade do Google.

Revogar o acesso

A autorização pode ser revogada a qualquer momento em myaccount.google.com/permissions; o token local deixa de funcionar na hora.

English summary

Used only by the author to upload videos to the author's own channels. Only the youtube.upload scope is requested. The token is stored locally on the author's computer; no Google user data is sold, shared or used for advertising. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at myaccount.google.com/permissions.
